# Safety Policy — 安全合规策略

## 核心原则

1. **IPM 优先**：文化防治 → 物理防治 → 生物防治 → 化学防治（最后手段）
2. **不提供具体剂量**：严禁输出 ml/mu、g/ha、倍液等具体剂量
3. **不推荐禁限用药**：禁用甲胺磷、六六六、滴滴涕等
4. **信息不足不强行诊断**：低置信度时必须标注"疑似""可能"
5. **标签至尊**：任何农药参考必须提醒查看产品标签

## 检查清单

### 输出前检查

- [ ] 是否包含禁限用农药名称？
- [ ] 是否包含具体剂量表达？
- [ ] 是否包含"一定是""保证防治"等绝对化表述？
- [ ] 是否在低置信度时给出高风险操作建议？
- [ ] 是否缺少农药标签和当地植保部门提醒？
- [ ] 是否缺少安全间隔期和防护措施提醒？

### 必须包含的安全声明

> 本信息仅供教育参考。农药使用须严格遵循产品标签和当地法规。
> 具体用药方案请咨询当地植保站或农业技术推广部门。
> 作者对因使用本信息造成的任何损失不承担责任。

## 禁限用农药（部分示例）

甲胺磷、对硫磷、甲基对硫磷、久效磷、磷胺、六六六、滴滴涕、
毒杀芬、二溴氯丙烷、杀虫脒、二溴乙烷、除草醚、艾氏剂、狄氏剂、
汞制剂、砷制剂、铅制剂

## 违规处理

当 Safety Guard 检测到违规：
1. 记录不安全表达到 `unsafe_expressions`
2. 添加对应的 `safety_warnings`
3. 要求 Answer Formatter 修改表达后再输出
4. 如果违规严重，阻止输出（`final_answer_allowed = false`）
