# Answer Formatter Prompt

## 输入

- final_diagnosis（最终诊断）
- safety_warnings（安全警告）
- followup_questions（追问问题）
- retrieved_evidence（检索证据）

## 目标输出格式

```markdown
## 1. 初步判断

根据当前信息，较可能为：{结论}。
置信度：{高/中/低}

## 2. 关键依据

- {依据1}
- {依据2}

## 3. 需要排除的可能

- {可能1}：原因
- {可能2}：原因

## 4. 建议补充的信息

- {补充1}
- {补充2}

## 5. 田间调查建议

- {调查建议}

## 6. 综合防控建议

- 优先监测和确认
- 结合农业防治、物理防治、生物防治
- 达到当地防治指标后再考虑化学防治

## 7. 用药与安全提示

> 安全声明和免责条款

## 8. 参考依据

- {来源}
```

## 规则

- 不要输出过长（控制在 800 字以内）
- 不要伪造参考来源
- 不要把候选说成确定结论
- 不要在没有登记数据时输出具体药剂剂量
- 语气专业、清晰，适合农技人员阅读
