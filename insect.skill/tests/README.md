# Tests Directory

本目录用于存放农业昆虫 Skill 的测试用例和验证脚本。当前为框架版本（0.1.0），不包含真实测试案例。

## 测试组织计划

### 1. 文本诊断测试 Text Diagnosis Tests

测试 Agent 在纯文本输入场景下的诊断能力：

- 用户以文字描述害虫和受害症状时，是否正确填充诊断槽位
- 是否正确识别信息不足并追问
- 是否正确处理非昆虫问题的转交
- 当知识库有数据时，候选害虫排序是否合理

### 2. 图片观察测试 Image Observation Tests

测试 Agent 在图片输入场景下的观察和推理能力：

- 是否按 `image_observation_checklist.md` 逐项观察
- 是否在图像不清晰时降低置信度并说明原因
- 是否客观描述后推断，而非跳过观察直接定种
- 是否在只有单张模糊图片时拒绝高置信鉴定

### 3. 追问能力测试 Follow-up Questioning Tests

测试 Agent 在信息不足时的追问策略：

- 是否按缺失槽位类型选择对应追问模板
- 单次追问数量是否控制在 3-4 个以内
- 追问是否具体可操作（而非泛泛的"请提供更多信息"）

### 4. 不确定性测试 Uncertainty Handling Tests

测试 Agent 表达不确定性的方式：

- 是否正确使用"疑似""可能""需要进一步确认"等限定语
- 是否明确标注置信度等级
- 是否在无法鉴定时诚实说明而非强行给出答案

### 5. 安全用药测试 Pesticide Safety Tests

测试 Agent 在涉及农药时的安全把控：

- 是否遵守"不提供具体剂量"规则
- 是否优先推荐非化学防控措施
- 是否包含必要的安全声明
- 是否提醒查看产品标签和咨询当地植保部门

### 6. 专家评审样例 Expert Review Samples

面向农技人员的输出测试：

- 报告格式是否完整
- 鉴别分析是否有理有据
- 不确定性说明是否充分
- 参考文献是否标注

## 添加测试用例的规范

当进入知识注入阶段后（版本 ≥ 0.2.0），测试用例应按以下规范组织：

```
tests/
├── README.md                # 本文件
├── test_text_diagnosis/     # 文本诊断测试
│   ├── case_001.md          # 每个案例：输入描述 + 期望行为
│   └── ...
├── test_image_obs/          # 图片观察测试
│   ├── image_001.jpg        # 测试图片
│   ├── image_001_expected.md # 期望的观察输出
│   └── ...
├── test_followup/           # 追问能力测试
├── test_uncertainty/        # 不确定性测试
├── test_pesticide_safety/   # 安全用药测试
└── test_expert_reports/     # 专家评审样例
```
