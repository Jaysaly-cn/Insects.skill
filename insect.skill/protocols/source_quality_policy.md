# Source Quality Policy

本文档定义知识来源的可信度分级标准和处理规则。

## 1. 可信度分级

### high — 高可信

满足以下条件之一的来源：

- 中国农业农村部、国家林业和草原局等国家级机构发布的官方植保资料
- 各省（自治区、直辖市）植保植检站发布的病虫害测报与防治指南
- 经同行评审的学术期刊论文（中文核心期刊、SCI 期刊）
- 正式出版的高等院校教材、专著
- FAO（联合国粮农组织）、CABI、EPPO 等国际权威机构的技术文件
- 国家/行业标准（GB、NY、LY 等）

**使用规则**: 可直接作为知识卡片的事实依据。

### medium — 中等可信

- 农业科研院所、农业大学官网发布的技术文章
- 正式出版的科普读物（需注明版本和页码）
- 经专家审定的数据集
- 企业发布的经官方登记的农药产品标签信息

**使用规则**: 可作为辅助来源，需与其他来源交叉验证。在知识卡片中标注「来源可靠性: 中等」。

### low — 较低可信

- 企业宣传材料、产品推广页
- 普通农业资讯网站、博客
- 论坛、社交媒体上的经验分享
- 未标注作者和日期的网络文章

**使用规则**: 一般不作为知识卡片的主要事实来源。如确需引用，须在 `notes` 中明确标注来源局限性和使用风险。

### unknown — 未知

- 无法确定出处、作者、发布日期的资料
- 个人口头交流（未经书面记录）

**使用规则**: 不得作为知识卡片的事实来源。可记录在 `sources/staging/` 中留待核实。

## 2. 来源登记要求

每个来源在 `sources/source_registry.json` 中登记时，必须包含：

| 字段 | 必填 | 说明 |
|------|------|------|
| source_id | 是 | 唯一标识符，格式 SRC_NNNN |
| title | 是 | 资料标题 |
| source_type | 是 | 资料类型 |
| publisher | 推荐 | 发布机构 |
| url | 推荐 | 网络链接（如有） |
| accessed_at | 推荐 | 访问日期 |
| license | 推荐 | 使用许可/版权信息 |
| reliability | 是 | 可信度分级 |
| notes | 推荐 | 补充说明 |

## 3. 冲突资料处理

当不同来源对同一事实给出矛盾信息时：

1. **记录冲突** — 在 fact_extracts 中标注 conflicting 状态
2. **优先级排序** — 按可信度排序：high > medium > low > unknown
3. **同等可信度冲突** — 同时保留两种说法，在知识卡片中注明「存在争议」或「不同来源说法不一」
4. **不强行统一** — 不要人工选择一个而丢弃另一个，除非有明确证据支持

示例：

```json
{
  "field": "damaging_stages",
  "claim": "以幼虫为害为主",
  "source_id": "SRC_0001",
  "evidence": "原文: ...幼虫取食叶片...",
  "confidence": "high",
  "notes": "与 SRC_0003 一致"
},
{
  "field": "damaging_stages",
  "claim": "成虫也可为害",
  "source_id": "SRC_0002",
  "evidence": "原文: ...成虫亦取食...",
  "confidence": "medium",
  "notes": "CONFLICT: SRC_0001 和 SRC_0003 未提及成虫为害"
}
```

## 4. 关键事实可追溯原则

以下字段被视为「关键事实」，必须有来源支持：

- name_latin（拉丁学名）
- taxonomy（分类地位）
- damaging_stages（为害虫态）
- typical_symptoms（典型症状）
- diagnostic_features（关键识别特征）
- similar_pests（相似害虫）
- 综合防控建议中涉及的生物学习性

关键事实无来源支持时，标注「当前来源不足，需进一步确认」，不得写成确定事实。

## 5. 非关键事实

以下字段允许基于常识或 inference 补充，但仍建议标注来源：

- regions（发生区域）— 优先以官方测报为准
- seasons（发生季节）— 优先以文献记录为准
- 田间调查建议 — 可为通用建议

## 6. 禁止使用的来源

无论可信度如何，以下内容**不得**作为知识来源：

- 被撤稿的学术论文
- 已被官方更正的错误信息
- 明确标注「仅供参考，不作为防治依据」的资料
- 过期的农药登记信息
- 版权受限且未获授权的内容（如需引用，仅可引用公开摘要或改写后注明出处）
