# Image Observation Checklist

When a user uploads images of insects, crop damage, or field conditions,
follow this structured observation protocol. **Describe first, infer
second.**

## 1. Image Quality Assessment

Before analysing content, note:

- [ ] Focus: sharp or blurry?
- [ ] Lighting: well-lit, backlit, shadowed?
- [ ] Angle: dorsal, lateral, ventral, oblique?
- [ ] Scale: is a reference object visible (coin, ruler, finger)?
- [ ] Resolution: sufficient to see diagnostic features?

**If image is too poor**: Do not guess. State that identification is not
possible and request better images with specific guidance (e.g. "please
take a dorsal photo with a coin for scale").

## 2. Insect Morphology (if insect is visible)

### 2.1 Life Stage

- [ ] Egg mass / single egg
- [ ] Larva (caterpillar, grub, maggot)
- [ ] Nymph
- [ ] Pupa / cocoon
- [ ] Adult
- [ ] Cannot determine

### 2.2 Body Size

- [ ] Estimate in mm (if scale available)
- [ ] Relative to common object (e.g. "rice grain size", "thumb nail size")

### 2.3 Body Colour

- [ ] Primary colour(s)
- [ ] Pattern (stripes, spots, bands, uniform)
- [ ] Iridescence / metallic sheen

### 2.4 Body Shape

- [ ] Elongate, oval, round, flattened, cylindrical
- [ ] Segmentation visible?

### 2.5 Head

- [ ] Head capsule colour
- [ ] Mouthpart type (chewing, piercing-sucking, siphoning, sponging)
- [ ] Eye type (compound, ocelli)

### 2.6 Antennae

- [ ] Type (filiform, moniliform, serrate, pectinate, clavate, capitate,
      lamellate, geniculate, aristate, setaceous)
- [ ] Length relative to body
- [ ] Number of segments (if countable)

### 2.7 Wings (adults)

- [ ] Number of wing pairs
- [ ] Wing type (membranous, elytra, hemelytra, tegmina, halteres)
- [ ] Wing colour and pattern
- [ ] Venation visible?

### 2.8 Legs

- [ ] Number of legs
- [ ] Leg type (cursorial, fossorial, saltatorial, raptorial, natatorial)
- [ ] Tarsal segments
- [ ] Prolegs present (larvae)?

### 2.9 Body Surface

- [ ] Smooth, rough, hairy, spiny, waxy
- [ ] Setae / hairs: colour, density, arrangement
- [ ] Tubercles / spines / horns

## 3. Plant Damage Symptoms (if plant damage is visible)

### 3.1 Damaged Plant Part

- [ ] Leaf, stem, root, fruit, flower, seedling, whole plant

### 3.2 Feeding Pattern

- [ ] Chewing: holes, notches, skeletonisation, edge feeding
- [ ] Piercing-sucking: stippling, yellowing, silvering, distortion
- [ ] Mining: leaf mines (serpentine or blotch)
- [ ] Boring: stem / fruit entry holes with frass
- [ ] Galling: abnormal growths
- [ ] Rolling / folding / webbing

### 3.3 Indirect Signs

- [ ] Frass (insect excrement) — colour, shape, location
- [ ] Honeydew / sooty mould
- [ ] Entry / exit holes
- [ ] Silk webbing
- [ ] Egg masses on plant surfaces
- [ ] Cast skins / exuviae

## 4. Field Context (if visible)

- [ ] Distribution pattern: single plant, patch, edge effect, uniform
- [ ] Crop growth stage
- [ ] Adjacent crops / weeds

## 5. Observation → Inference

After completing the checklist, summarise:

1. **Objective observations** (what is actually seen).
2. **Tentative taxonomic placement** (order, family) based on morphology.
3. **Species candidates** (if sufficient detail), with confidence
   explicitly stated.
4. **Missing information** needed for stronger identification.

## Important Reminders

- **Never** claim species-level identification from a single blurry photo.
- If diagnostic features are not visible, say so.
- Use qualifying language: "appears to be", "consistent with", "possibly".
- Multiple angles (dorsal + lateral + ventral) greatly improve accuracy.
